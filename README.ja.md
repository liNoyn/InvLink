# InvLink

[English](README.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md)

複数の Bedrock Dedicated Server の間でプレイヤーのデータを共有する [LeviLamina](https://github.com/LiteLDev/LeviLamina) の MOD です。つないだどのサーバーでも、同じ持ち物で遊べます。
プロキシのプラグインは要りません。サーバー同士がフォルダを 1 つ共有するだけです。

## 共有するもの

```
共有
├─ インベントリ 0-35
├─ ヘルメット
├─ チェストプレート
├─ レギンス
├─ ブーツ
├─ オフハンド
├─ 選んでいるホットバーの位置
├─ エンダーチェスト 0-26
└─ 経験値
   └─ 合計の経験値
```

アイテムはそのまま運びます（エンチャント・名前・耐久値・シュルカーボックスの中身なども）。
それ以外はサーバーごとのままです：位置・次元・リスポーン地点・ゲームモード・権限・体力・満腹度・ポーションの効果・レシピなど。

## しくみ

- つなぐサーバーは、すべて同じ**共有フォルダ**を指します。そこに、プレイヤーごとの最新の共有データ（Minecraft の NBT をそのまま）と、今どのサーバーが**持ち主**かを置きます。
- **入る**：BDS がワールドからプレイヤーのデータを読む所（`LevelStorage::loadServerPlayerData`）で、共有データを差し込みます。プレイヤーができる前なので、最初から正しい持ち物が届きます。そのサーバーが持ち主になります。
- **遊んでいる間**：`saveSeconds`（既定 60 秒）ごとに保存します（落ちた時の備え）。
- **抜ける**（終了・キック・別のサーバーへの `/transfer` など）：すぐに保存して手放し、次のサーバーが受け取れるようにします。
- **増えない**：別のサーバーがまだ持ち主で、そのサーバーが動いている間は、入ろうとした人に「数秒待ってから、もう一度入ってください」と伝えます。持ち主のサーバーが手放さないまま止まった時は、最後の保存から始めます（少し戻ることはあっても、増えることはありません）。
- **控え**：あるサーバーが、プレイヤーのもともとの持ち物を初めて共有の持ち物に置き換える時、元の持ち物を `backup/<サーバー>/<uuid>.nbt` に 1 回だけ控えます。共有データの古い版は `players/<uuid>.history/` に残します（`keepHistory`、既定 20 件）。
- ファイルは、一時ファイルに書いてから名前を変えて置き換えます。読む側が書きかけのファイルを見ることはありません。

## 必要なもの

- LeviLamina **26.60.0** を入れた Bedrock Dedicated Server（BDS 1.26.60.x）。サーバーの版に合わせてビルドしてください。
- つなぐサーバーすべてから、共有フォルダが見えること（同じマシン、または名前の変更ができるネットワークフォルダ）。
- つなぐサーバーは、同じアドオンを入れてください（どのサーバーにも同じアイテムがあるように）。

## 入れ方

1. ビルドした `InvLink` フォルダを、つなぐサーバーすべての `mods/` に入れます。
2. 一度起動すると、`mods/InvLink/config.json` ができます。
3. `server` にこのサーバーの名前（ほかと重ならないもの）、`store` に共有フォルダ（どのサーバーも同じ場所）を書いて、再起動します。

```json
{
  "server": "s1",
  "store": "../../../.invlink",
  "language": "ja",
  "kickMessage": "",
  "saveSeconds": 60,
  "aliveTimeoutSeconds": 30,
  "keepHistory": 20
}
```

| キー | 意味 |
|---|---|
| `server` | このサーバーの名前（つなぐサーバーの間で重ならないもの）。空なら何もしません。 |
| `store` | 共有フォルダ。相対パスは MOD のフォルダからの場所です。 |
| `language` | ログとプレイヤーへのメッセージの言語。`en`・`ja`・`zh`。 |
| `kickMessage` | 待ってもらう時（別のサーバーがまだ持ち主の時）に出すメッセージ。空なら決まった文。 |
| `saveSeconds` | 遊んでいる人を保存する間隔（10 以上）。 |
| `aliveTimeoutSeconds` | この秒数、心拍が来ないサーバーは止まったとみなします（10 以上）。 |
| `keepHistory` | プレイヤーごとに残す共有データの古い版の数。 |

**動いているサーバーで使い始める前に、つなぐサーバーすべてのワールドをバックアップしてください。**

## ビルド

[xmake](https://xmake.io) と clang-cl（LLVM）、MSVC のビルドツールが要ります。

```bash
xmake repo -u
xmake f -p windows -a x64 -m release -y --target_type=server
xmake
```

`bin/InvLink/` にできます。

## 試験

手元の 2 台（BDS 1.26.60.6 ＋ LeviLamina 26.60.0）で、試験用のクライアントと本物のクライアントで確かめました。

- インベントリ・防具 4 つ・オフハンド・エンダーチェスト・経験値が、どちらの向きにも引き継がれる（体力・効果は共有データに入らない）
- 片方から抜けてすぐもう片方に入る：抜けた時に保存し、入った時に読み込む
- 片方にいるまま、もう片方に入る：メッセージ付きで断られ、増えない
- 初めての時の控えができる
