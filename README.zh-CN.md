# InvLink

[English](README.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md)

一个 [LeviLamina](https://github.com/LiteLDev/LeviLamina) 模组，在多台 Bedrock Dedicated Server 之间共享玩家数据，让玩家在所有连接的服务器上拥有相同的物品。
不需要代理插件：服务器之间只需共享一个文件夹。

## 共享的内容

```
共享
├─ 背包 0-35
├─ 头盔
├─ 胸甲
├─ 护腿
├─ 靴子
├─ 副手
├─ 当前选中的快捷栏位置
├─ 末影箱 0-26
└─ 经验
   └─ 总经验
```

物品原样传送（附魔、名称、耐久、潜影盒内容等全部保留）。
其他内容各服务器独立：位置、维度、重生点、游戏模式、权限、生命值、饥饿值、药水效果、配方等。

## 原理

- 所有连接的服务器都指向同一个**共享文件夹**。其中为每个玩家保存最新的共享数据（原样的 Minecraft NBT，不做转换），以及当前由哪台服务器**持有**。
- **进入服务器**：InvLink 挂钩 BDS 从世界读取玩家数据的时刻（`LevelStorage::loadServerPlayerData`），在玩家创建之前注入共享数据，因此客户端一开始就收到正确的物品。该服务器成为持有者。
- **游玩中**：每 `saveSeconds`（默认 60 秒）保存一次，以防服务器崩溃。
- **离开**（退出、被踢出、`/transfer` 到其他服务器等）：立即保存并释放，下一台服务器即可接管。
- **不会复制**：当另一台服务器仍持有数据并且正在运行时，进入的玩家会被提示等待几秒后重新进入。如果该服务器未释放就停止了，则使用最后一次保存（可能稍有回退，但绝不会复制）。
- **备份**：某台服务器第一次用共享物品替换玩家原有物品时，会将原有物品备份一次到 `backup/<服务器>/<uuid>.nbt`。共享数据的旧版本保存在 `players/<uuid>.history/`（`keepHistory`，默认 20 个）。
- 所有文件都先写入临时文件再重命名，读取方永远不会看到写了一半的文件。

## 要求

- 安装了 LeviLamina **26.60.0** 的 Bedrock Dedicated Server（BDS 1.26.60.x）。请按服务器的版本构建。
- 所有连接的服务器都能访问共享文件夹（同一台机器，或支持重命名的网络文件夹）。
- 连接的服务器应安装相同的附加包，确保每个物品在每台服务器上都存在。

## 安装

1. 将构建好的 `InvLink` 文件夹复制到每台连接服务器的 `mods/` 中。
2. 启动一次服务器，会生成 `mods/InvLink/config.json`。
3. 将 `server` 设为本服务器的唯一名称，将 `store` 设为共享文件夹（所有服务器相同），然后重启。

```json
{
  "server": "s1",
  "store": "../../../.invlink",
  "language": "zh",
  "kickMessage": "",
  "saveSeconds": 60,
  "aliveTimeoutSeconds": 30,
  "keepHistory": 20
}
```

| 键 | 含义 |
|---|---|
| `server` | 本服务器的名称，在连接的服务器之间唯一。为空时 InvLink 不做任何事。 |
| `store` | 共享文件夹。相对路径以模组文件夹为基准。 |
| `language` | 日志和玩家提示的语言：`en`、`ja` 或 `zh`。 |
| `kickMessage` | 需要玩家等待时（数据仍由其他服务器持有）显示的消息。为空时使用内置文本。 |
| `saveSeconds` | 保存在线玩家的间隔（最小 10）。 |
| `aliveTimeoutSeconds` | 超过此秒数没有心跳的服务器视为已停止（最小 10）。 |
| `keepHistory` | 每个玩家保留的共享数据旧版本数量。 |

**在正式服务器上启用之前，请备份所有连接服务器的世界。**

## 构建

需要 [xmake](https://xmake.io)、clang-cl（LLVM）以及 MSVC 构建工具。

```bash
xmake repo -u
xmake f -p windows -a x64 -m release -y --target_type=server
xmake
```

模组输出到 `bin/InvLink/`。

## 测试

在本地两台服务器（BDS 1.26.60.6 + LeviLamina 26.60.0）上，使用测试客户端和真实客户端验证：

- 背包、四件盔甲、副手、末影箱和经验在两个方向上都能正确继承（生命值和效果不在共享数据中）
- 离开一台服务器后立即进入另一台：离开时保存，进入时读取
- 仍在第一台服务器在线时进入第二台：被拒绝并显示提示，不会复制
- 首次的备份已生成
